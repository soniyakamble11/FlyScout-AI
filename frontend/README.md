# FlyScout AI - Frontend Client

Modern React + TypeScript + Vite dashboard for the FlyScout AI Outbound BDR Platform.

## Features
- **Design System**: Glassmorphism aesthetic with dark mode tokens, Plus Jakarta Sans typography, and subtle micro-animations.
- **State Management**: Context API for Theme and Multi-Agent Pipeline execution streaming.
- **Component Architecture**: Reusable UI atomic components (`Button`, `Card`, `Input`, `Modal`, `Table`, `Badge`, `Loader`, `EmptyState`, `Toast`).
- **Telemetry Visualizer**: Real-time SSE streaming status tracker for the 7 autonomous AI agents.
- **Email Editor**: Interactive multi-touch cold email sequence reviewer and inline editor.

## Local Setup

```bash
npm install
npm run dev
```

Runs on: `http://localhost:5173`
